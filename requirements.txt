# Auth.
# bcrypt is held below 4.1 on purpose: passlib 1.7.4 reads bcrypt.__about__,
# which 4.1 removed. The read is wrapped in a bare except, so newer bcrypt
# only logs a spurious "error reading bcrypt version" warning rather than
# failing -- but passlib has been unmaintained since 2020 and is not tested
# against current bcrypt or Python 3.14, so the pin keeps a known-good pair.
# Longer term, migrate to pwdlib[bcrypt] or call bcrypt directly.

bcrypt==4.0.1
# python-jose is likewise unmaintained; pyjwt is the better-supported choice
# if this is ever revisited.
